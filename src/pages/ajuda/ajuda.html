Manual rapido

Central de Ajuda

Rotina recomendada

  1. Funcionario entra com seu proprio usuario.
  2. Abre o caixa no inicio do expediente.
  3. Registra vendas, pagamentos e clientes durante o dia.
  4. Usa Produtos somente quando a empresa quiser catalogo ou estoque.
  5. Fecha o caixa no fim do expediente com o valor contado.
  6. Administrador confere financeiro, auditoria, contas e usuarios.

Operacoes financeiras e cancelamentos pedem confirmacao. O sistema evita apagar definitivamente dados importantes.

Vendas

Use venda manual para lojas pequenas com itens variados. Use produtos cadastrados quando houver catalogo, codigo de barras ou estoque controlado.

  • Venda paga entra nos totais do caixa.
  • Venda fiada aumenta a divida do cliente.
  • Venda com produto controlado baixa o estoque.
  • Cancelamento restaura estoque e ajusta divida quando necessario.

Clientes e cobranca

Cadastre cliente para acompanhar fiado, pagamentos, telefone e historico. A tela Hoje calcula atraso pelo ultimo pagamento ou compra fiada; a data do próximo vencimento impede a cobrança enquanto ainda for hoje ou futura.

  • Cliente com saldo entra como atrasado após 45 dias sem pagamento ou nova compra fiada.
  • Entre 30 e 44 dias, aparece em “Precisam de atenção”; até 29 dias, permanece regular.
  • Pagamento parcial reinicia a contagem. A data digitada no cadastro não altera o cálculo.
  • O campo “Último pagamento registrado” deve conter a data real do pagamento mais recente. Uma data antiga faz a contagem começar no passado.
  • O próximo vencimento é uma data completa única; ele não se repete automaticamente todo mês. Atualize-o quando combinar o próximo pagamento.
  • A lista de atraso mostra do maior tempo para o menor.
  • O rascunho só pode ser aberto se o cliente estiver em atraso, tiver telefone válido e consentimento registrado.

Caixa

O caixa serve para conferir o dinheiro do operador no dia. Ele nao substitui a area financeira do administrador.

  • Abra com o valor inicial de troco.
  • O sistema soma vendas pagas e pagamentos recebidos.
  • Saidas registradas pelo administrador reduzem o esperado.
  • No fechamento, informe o valor contado e registre observacao se houver diferenca.

Produtos e estoque

Produto cadastrado ajuda em busca rapida, codigo de barras, preco padrao e estoque. Para loja simples, ainda e possivel vender item livre.

  • Quantidade inicial pode ser informada ao criar produto.
  • Depois disso, altere quantidade por Movimentar estoque.
  • Entrada, saida e ajuste ficam registrados na auditoria.
  • Produto com estoque controlado nao pode ficar negativo.

Administracao

Area reservada para administrador: financeiro, contas, saidas, auditoria, usuarios e configuracoes da empresa.

  • Use Usuarios para criar um acesso por funcionario.
  • Use Permissoes para limitar financeiro, administracao e cancelamentos.
  • Use Configuracoes para trocar nome, logo, WhatsApp e modo de uso.
  • Use Auditoria para investigar venda, pagamento, cancelamento, estoque e contas.

Seguranca operacional

  • Evite compartilhar usuario entre funcionarios.
  • Troque a senha padrao antes de usar em producao.
  • Faca backup antes de atualizar o sistema ou trocar banco.
  • Feche o app ao sair do computador para exigir login novamente.
  • Operacoes erradas devem ser canceladas, nao apagadas do historico.

Instalacao e atualizacao

  1. Baixe a versao atualizada do sistema.
  2. Copie o banco antigo `Banco_dados.db` para a pasta do sistema novo.
  3. Abra o app uma vez para ele criar colunas e tabelas novas.
  4. Teste vendas, clientes, caixa e administracao antes de usar no dia real.
  5. Para gerar app Windows, use `npm run package:win`.
